Privacy Policy

Topshark Shorts Uploader
Last updated: October 18, 2026

Who this applies to

Topshark Shorts Uploader is a private tool. Its only user is the owner of the Seika Sunswirl (サンスワール せいか) Ch. YouTube channel, who uses it to upload their own videos to their own channel. It is not offered to the public.

Google user data the tool accesses

  • youtube.upload: used only to upload videos and set their titles, descriptions, privacy settings and publish times on the owner's own channel.
  • youtube.readonly: used only to read the status of the channel's own videos (for example, to confirm an upload finished or a video is scheduled).

The tool does not access any other Google data, and it does not access anyone else's account.

What is stored

The tool stores only an OAuth token, on the owner's own computer, so that it can keep uploading without signing in each time. It does not keep a copy of any YouTube account data on any server. There is no database, no analytics, no cookies, and no tracking in the tool.

Sharing

No data is shared, sold, rented or transferred to anyone. Google user data is not used for advertising and is not used to train AI models. Data is used only to upload and check the owner's own videos, consistent with the Google API Services User Data Policy, including its Limited Use requirements.

How to revoke access

You can remove the tool's access at any time:

  1. Go to your Google Account's Third-party apps & services page (Google Account → Security → Your connections to third-party apps & services).
  2. Select Topshark Shorts Uploader (it may appear under the project name).
  3. Choose Delete all connections / Remove access.

Once access is revoked, the stored token stops working. The owner can also delete the token file from their computer at any time.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
